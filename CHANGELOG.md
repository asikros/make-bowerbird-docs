## [0.1.0] - 2026-01-10

### Added
- Initial release of Bowerbird Make documentation repository
- Make Style Guide: Comprehensive coding standards for Makefiles including:
  - Documentation guidelines (macro/function docstrings)
  - Naming conventions (public vs. private macros)
  - Variable naming patterns
  - File operations best practices (blanking vs. removing files)
  - Test file organization recommendations
- Testing Guide: Complete testing methodology including:
  - Test file organization principles
  - Testing error messages (shell-generated vs. Make-generated)
  - Corner case testing strategies
  - Recursive Make testing techniques
- Testing Workflow: Step-by-step instructions for running tests
